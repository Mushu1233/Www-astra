Установка по шагам

Инструкции для Windows и Android.

Windows — Шаг 1: Скачайте установщик

Скачайте Установка Astra Browser.exe со страницы «Скачать».

Windows — Шаг 2: Пройдите мастер

Запустите файл, пройдите шаги: лицензия, параметры, путь установки.

Windows — Шаг 3: Запуск

После установки на рабочем столе появится ярлык Astra Browser. Запустите его.

Android — Шаг 1: Скачайте APK

Скачайте файл AstraBrowser-release.apk на устройство.

Android — Шаг 2: Разрешите установку

Включите «Установку из неизвестных источников» для вашего браузера/файлового менеджера.

Android — Шаг 3: Установите

Откройте APK и нажмите «Установить». Готово!
